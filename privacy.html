Privacy Policy

Last updated: October 2, 2026

Tab Dock collects nothing. There is no account, no analytics, no ads, and no server. Everything the extension needs stays in your browser, on your computer.

What the extension stores

To draw the dock, Tab Dock keeps a list of your open tabs, grouped by website:

  • the address (URL) and title of each open tab, and which window it belongs to;
  • the icon of each website in the dock.

This list is held in the browser’s memory and is not written to your disk: it is erased when you close the browser. Tab Dock does not keep a browsing history: when you close a tab, it disappears from the list.

Only your dock preferences are saved on your device, so that they survive a restart:

  • whether the dock sits at the top or bottom of the window;
  • the order of its icons, saved as the names of the websites currently in your dock (for example, github.com), without any page address or title.

These preferences live in the extension’s own private storage, which websites cannot read. Nothing is synced to your browser account, nothing is ever sent anywhere, and everything is deleted when you uninstall Tab Dock.

Tab Dock does not run in private (incognito) windows.

What the extension sends

Nothing, to me or to anyone else. Tab Dock has no telemetry, no crash reporting, and no remote server to send data to.

One technical detail, for completeness: to show website icons, Chrome, Edge and Brave use the browser’s own built-in icon cache. Firefox has no such cache for extensions, so there Tab Dock downloads each icon from the address the website itself declares, without cookies. It is the same icon your browser already loads for the tab bar, and the request goes to wherever the website hosts it, never to Tab Dock.

Why it asks for these permissions

Read your tabs
To list the title, address and icon of your open tabs in the dock, and to switch to, open or close a tab when you click it.
Access to all websites
The dock is displayed on top of every page you visit, so the extension has to be allowed to run on every site. It only adds the dock to the page: it does not read, collect or change the page’s content. To draw it, the dock on a page receives the website names, titles and icons of the tabs open in the same window, never their addresses, and it is kept isolated from the page’s own scripts. Your browser shows this permission as “read and change all your data on all websites” because it cannot express anything narrower. On Firefox, this permission is also what allows Tab Dock to download website icons.
Storage
On Chrome, Edge and Brave, to hold the tab list described above in memory for the browser session. On Firefox, only to erase what older versions of Tab Dock had saved. Your dock preferences use the extension’s own private database, which needs no permission.
Favicons (Chrome, Edge, Brave)
To display website icons from the browser’s cache.

Sharing and selling

Tab Dock does not share, sell or transfer any data to third parties, because it has none to share.

This website

tabdock.org sets no cookies and uses no analytics or trackers. It is hosted on GitHub Pages, and GitHub may log technical information such as your IP address for security purposes (see the GitHub Privacy Statement). To show the latest version number, the homepage asks GitHub’s public API for it, so your browser connects to api.github.com.

The install buttons take you to the Chrome Web Store or Firefox Add-ons, which have their own privacy policies.

Don’t take my word for it

Tab Dock is open source. You can read every line of the extension on GitHub.
